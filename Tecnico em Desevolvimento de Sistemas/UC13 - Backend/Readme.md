## 📖 Sobre o Projeto

Este projeto é um **backend modular** desenvolvido em TypeScript como parte do curso de **Desenvolvimento de Sistemas do SenacRS**.

O objetivo é demonstrar uma **arquitetura limpa e escalável**, com separação clara de responsabilidades, utilizando:

- **MVC** (Model-View-Controller) adaptado para APIs REST
- **Repository Pattern** para abstração do banco de dados
- **Service Layer** para regras de negócio
- **DTOs e Schemas** para validação de dados com Zod
- **TypeORM** para interação com o banco MySQL
